# Part 1: Understanding Operators
| Remember: Scratch's green Operators blocks Round blocks report a number: ( ) + ( ) ( ) - ( ) ( ) * ( ) ( ) / ( ) Pointed blocks report true or false: < ( ) > ( ) > < ( ) < ( ) > < ( ) = ( ) >. Logic blocks join them: and (both sides true), or (at least one side true), not (flips the result). Symbol or name? The symbol is read one way, but the operation has a different name: + is read “plus” (Addition), - is read “minus” (Subtraction), * is read “times” (Multiplication) and / is read “divided by” (Division). |
