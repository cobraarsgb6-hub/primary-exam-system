# مواصفات المرحلة P9: التوثيق والصيانة الموحدة (010-docs-maintenance)

## 1. ملخص الميزة
توحيد وتحديث وثائق النظام بالكامل، وتثبيت المرجع الموحد للحقيقة (Single Source of Truth) بحيث يكون هناك ملف حالة نشط وحيد (`CURRENT_STATUS_AR.md`) وخطة نشطة موحدة (`ROADMAP_SPECKIT_AR.md` و`specs/`)، مع وسم كافة التقارير والخطط السابقة بعلامة "أرشيف تاريخي" لتجنب أي تشتت أو تعارض في المعلومات. كما تتضمن المرحلة تحديث `README.md` الشامل، توثيق الفرق الجوهري بين `Index.html` (Google Apps Script) و`index.html` (GitHub Pages / Android WebView)، سجل المشاكل المتكررة والحلول الهندسية المعتمدة (Troubleshooting & Known Pitfalls)، وجدول الصيانة والمراجعة الدورية للحصص والرموز السرية.

## 2. أهداف الإنجاز (Objectives)
1. **ملف حالة نشط وحيد:** التأكيد على `CURRENT_STATUS_AR.md` كمرجع وحيد للحالة الراهنة مع ربط كل إنجاز فيه بنتيجة اختبار أو دليل تشغيلي قاطع.
2. **وسم الوثائق التاريخية:** إضافة ترويسة تنبيهية بارزة (Historical Archive Banner) في مقدمة كل ملف وثائقي أو خطة مرحلية قديمة لا تعكس الكود الحي الحالي.
3. **تحديث الـ README والبيئة التشغيلية:**
   - شرح المعمارية المزدوجة ونقاط النهاية (GAS WebApp + GitHub Pages + Android APK).
   - توضيح دور `Index.template.html`، `bundle.py`، `Index.bundle.html`، `Index.html`، و`index.html`.
   - أوامر الاختبار والتشغيل (`npm test`, `run_all_e2e.py`).
4. **سجل المشاكل المتكررة (Known Pitfalls & Golden Rules):**
   - حظر تعليقات `//` داخل سياق كود JS أو القوالب المضمنة التي قد تنكسر عند الضغط أو الحقن.
   - شرط إضافة UTF-8 BOM (`\uFEFF`) عند تصدير CSV لبرنامج Excel على Windows.
   - شرط نشر Apps Script عبر `New Version` دائمًا لتفعيل التغييرات الحية.
   - تطبيع مدخلات الطلاب (NFKC, إزالة التشكيل، همزات، أرقام هندية/عربية).
5. **دليل الصيانة الدورية للحصص والرموز:**
   - جدول صلاحية ومراقبة الرموز السرية (`COLIGO_TOKEN`, `COLIGO_REFRESH_TOKEN`, `SYNC_SECRET`, `ADMIN_PIN`).
   - مراقبة حصص Google Apps Script (Quota) وحصص GitHub Actions.

## 3. معايير القبول (Acceptance Criteria)
1. وجود ترويسة أرشيف تاريخي واضحة على 14 ملف وثائقي قديم على الأقل.
2. `CURRENT_STATUS_AR.md` يحتوي على سجل كامل لجميع المراحل P0 حتى P9 موثقة بالأدلة وعدد الاختبارات الرسمي (119 اختبارًا).
3. `README.md` محدث وشامل ويحتوي على دليل التثبيت، الاختبار، النشر، والمعمارية.
4. اجتياز اختبارات النظام بالكامل بنسبة 100% (67 وحدة + 51 E2E + اختبار الملاحة).
